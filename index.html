User Guide

เลือกหรือสร้างงานClaim Type · Product · Model
  1. ไปที่หน้าหลักแล้วแตะ เลือกงานตรวจ เพื่อเปิดงาน NEW
  2. กรองด้วย Claim Type และ Product หรือค้นชื่อปัญหา
  3. ถ้าไม่มีงานในรายการ ให้แตะ สร้างงานตรวจ แล้วกรอกชื่อปัญหาและ Model
ตั้งค่าเกณฑ์Checking Method · Result 1–4
  1. กรอกวิธีตรวจและเกณฑ์อย่างน้อย 1 ข้อ
  2. แนบรูปตัวอย่าง OK/NG จากกล้องหรืออัลบั้มได้เมื่อเปิดใช้ที่เก็บรูป
  3. กด บันทึกและเริ่มตรวจ แล้วแตะดาวเพื่อปักงานไว้หน้าแรก
บันทึกผลรายคันSerial · Model · OK/NG
  1. เปิดงานแล้วกด เพิ่มผลตรวจรายคัน
  2. กรอก Serial และเลือก OK หรือ NG ให้ครบทุกเกณฑ์
  3. เพิ่มหมายเหตุหรือรูปประกอบได้ตามต้องการ แล้วกด บันทึกและตรวจคันถัดไป
จบงานและเปิดรายงานReports · PDF
  1. ตรวจทานผลแล้วกด จบการตรวจ ที่ท้ายหน้างาน
  2. ไปที่ Reports แล้วกด ดูรายงาน เพื่อเปิดผลทุกคัน
  3. กด ดาวน์โหลด PDF เมื่อไฟล์พร้อม
